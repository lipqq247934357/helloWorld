# 面向对象

## Java

    java是基于类的面向对象语言；
    类: 对某个东西的抽象；
    对象: 具体的某个东西;

## class

    1.属性
    2.方法

## 面向对象具体功能的操作的三步流程

步骤一：创建类，并设计类的内部成员（属性，方法）
步骤二：创建类的对象，比如Phone p1 = new Phone();
步骤三：通过对象，调用其内部声明的属性或方法，完成相关的功能；

每个对象实例都单独在堆里占据一块内存空间；

## 方法

    1.Java的方法必须声明在类里面

### 方法的声明

    权限类型 [其他修饰符] 返回值类型 方法名(形参列表)[throws 异常类型]  {

    }

    权限修饰符： public 缺省的 protected public

    返回值： 没有返回值是 void 否则指明返回的数据的类型

### 函数重载

    参数名相同；但参数数量不同,参数类型不同；
        不看返回值类型；
    编译器通过形参判断对应哪个具体的函数；

### 可变个数形参

    就是这个函数支持接收多个形参， 0 - n个；
    可变个数形参必须放在多个参数列表的最后一个，也必须只有一个；
