# 面向对象

## this关键字

    this的作用是在对象里表示对象自己或者在构造函数里表示正在创建的对象；

## 继承

    继承就是类之间可以通过extends关键字产生关联关系，继承的类可以使用被继承类的一些属性和方法；
    并且他们之间产生了is-XXX的关系，这样为多态提供了实现基础；
    子类 继承 父类所有成员；直接访问 受 private / 包访问限制。
    java支持多层的继承；但不支持一个类多个父类；

### 方法重写

    方法重写就是子类可以重写父类的方法，实现多态；
    方法重写规则：
        1.子类和父类相同的方法名和参数列表；
        2.子类的方法返回类型必须和父类方法返回类型相同或者为父类方法返回类型的子类型；
        3.子类的方法访问类型权限比父类方法访问权限更宽松或一样；
        4.子类的方法不能抛出比父类方法更宽泛的检查异常；

### super

    1.super可以调用父类的属性和方法和构造函数；
        key访问父类的变量，方法，构造函数；
    2.使用super.xxx调用父类的属性和方法；如果没有被重载的属性和方法，可以直接省略super关键字；
    3.尽量避开出现同名的属性；要不然给自己挖坑；
    4.调用父类构造器
        1.必须放在构造函数首行调用，不能和调用本类函数并存；否则编译错误；
        2.子类在没有写默认构造器的时候，或者默认构造器没有内容的时候，会默认调用父类的构造器;
    5.子类的构造器的特点
        1.子类构造器要不调用本类的其他构造器，要不调用父类的构造器，必然会调用其一；

### 继承的本质

    继承是子类可以复用父类的非私有成员。创建子类实例时，会沿着继承链从 Object 开始依次调用各级父类的构造器，完成对象的初始化；
    子类通过继承链访问父类、祖代类中允许访问的方法和属性。
    继承链上只创建一个对象（子类对象），父类构造器只是分层初始化这一个对象的不同部分。
    不是“父类对象存在但不可访问”，而是 “只有一个子类对象，它身上同时携带了所有父类继承下来的字段”。


## 多态

    父类的引用指向子类的对象
    用同一个父类型来接收和操作不同的子类型对象，但每个对象仍按自己的方式运行。
    编译时，认为是左边的类型，实际执行时执行的是右边的子类的方法；
    编译看左边，运行看右边；
    多态适用于方法，不适用于属性；

### 向下转型

    让声明为父类型的子类型实例可以访问父类型的方法；

### 向上转型

    可能出现子类有，但是父类没有的方法，然后报错；
    可以通过instanceof判断是否是子类的实例
    p2 instanceof Man // p2是否是Man的实例

## Object

    java中一个类没有默认显式声明的继承的父类就是Object；
    所有其他类直接或间接都是Object的子类；
    然后可以使用Object类的一些方法；

    Object类中没有声明属性；有一些方法；主要还是使用一些方法；

### Object方法

    1.equals
        1.比较两个对象地址是否相等；
        2.如果是字符串，他会重写equals方法，比较两个字符串的内容是否相等；
        3.其他的对象，他会重写equals方法，比较两个对象的内容是否相等；
    2.toString
        1.返回对象的字符串表示；
        2.默认返回对象的地址；
        3.可以重写toString方法，返回对象的属性值；
    3.hashCode
        1.返回对象的哈希码；
        2.默认返回对象的地址；
        3.可以重写hashCode方法，返回对象的属性值的哈希码；
