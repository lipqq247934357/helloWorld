# 面向对象

## static

    所有的对象共享的数据，直接通过类就可以访问；
    可以用来修饰类的成员属性和成员方法；

### 静态成员

    1.静态成员变量（也叫类变量）
        定义在类中、方法外面，使用static关键字修饰；
        示例：Phone 类中的 static int count;
    2.非静态成员变量（也叫实例变量）
        不使用static关键字修饰；
        示例：Phone 类中的 brand、price、color；

### 静态方法

    1.静态成员方法（也叫类方法）
        使用static关键字修饰；
        示例：Phone 类中的 static void call();
    2.非静态成员方法（也叫实例方法）
        不使用static关键字修饰；
        示例：Phone 类中的 void sendMessage();
    3.静态方法可以访问静态成员变量和静态成员方法；
    4.静态方法不能访问非静态成员变量和非静态成员方法；

## 代码块

    1.用来初始化对象；
    2.只可以使用 static 或者 缺省的 修饰代码块；
    3.静态代码块就是类初始化时执行一次的代码，编译后被放到 <clinit>() 方法里，由 JVM 在类加载的初始化阶段自动调用。
    4.实例代码块的内容编译之后其实会被插入到每个构造方法的开头。所以本质上它还是在构造方法里执行，只是写法上做到了复用。
        实例代码块和字段初始化会被编译进每个构造方法里，但位置是在 super() 之后，构造方法自己的代码之前，而不是简单地在“开头”。
    5.静态代码块只能访问静态成员变量和静态成员方法；
    6.实例代码块都可以访问；

## 给类的实例变量赋值的方式和顺序

    1.默认初始化
        默认初始化：变量的默认值；
    2.显式初始化
        显式初始化：在变量声明时，赋一个初始值；
    3.通过构造方法赋值
        通过构造方法赋值：在构造方法中，赋值；
    4.通过实例代码块赋值
        通过实例代码块赋值：在实例代码块中，赋值；
    5.通过执行对象的方法赋值
        通过执行对象的方法赋值：在方法中，赋值；

    显式初始化和实例代码块赋值的顺序和书写顺序一致；
    执行顺序：
    1 -> 2/3 -> 4 -> 5
