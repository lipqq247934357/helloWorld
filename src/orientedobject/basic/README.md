# 面向对象

## Java

    java是基于类的面向对象语言；
    类: 对某个东西的抽象；
    对象: 具体的某个东西;

## class

    1.属性
    2.方法

## 面向对象具体功能的操作的三步流程

步骤一：创建类，并设计类的内部成员（属性，方法）
步骤二：创建类的对象，比如Phone p1 = new Phone();
步骤三：通过对象，调用其内部声明的属性或方法，完成相关的功能；

每个对象实例都单独在堆里占据一块内存空间；

## 方法

    1.Java的方法必须声明在类里面

### 方法的声明

    权限类型 [其他修饰符] 返回值类型 方法名(形参列表)[throws 异常类型]  {

    }

    权限修饰符： private 缺省的 protected public

    返回值： 没有返回值是 void 否则指明返回的数据的类型

### 函数重载

    参数名相同；但参数数量不同,参数类型不同；
        不看返回值类型；
    编译器通过形参判断对应哪个具体的函数；

### 可变个数形参

    就是这个函数支持接收多个形参， 0 - n个；
    可变个数形参必须放在多个参数列表的最后一个，也必须只有一个；

### 函数传参，值引用和地址引用

    方法调用时，实参的值会传给形参。Java 只有值传递，没有 C/C++ 那种「把变量的地址直接传进去」的传参方式。

    可以按数据类型分成两类理解：

    1. 基本数据类型（int、double、boolean、char 等）
        传递的是数值本身的副本；
        方法内部修改形参，不会影响外面的实参；

    2. 引用数据类型（类、数组、String 等）
        变量里存的是引用（可以理解为堆上对象的地址）；
        传参时传递的是这个引用的副本，形参和实参仍然指向同一个对象；
        通过引用修改对象内部的数据，外面能看到变化；
        如果在方法内给形参重新赋值，让它指向新对象，外面的实参不会变；

    对比记忆：
        基本类型 → 传数值副本 → 改形参，不影响实参
        引用类型 → 传地址副本 → 改对象内容，影响实参；改形参指向，不影响实参

    示例：

        public static void changeInt(int n) {
            n = 100;                    // 只改了副本，外面不变
        }

        public static void changeArray(int[] arr) {
            arr[0] = 100;               // 改的是同一个数组对象，外面能看到
        }

        public static void reassignArray(int[] arr) {
            arr = new int[]{9, 9, 9};   // 形参指向了新数组，外面实参仍指向原数组
        }

        int num = 1;
        int[] nums = {1, 2, 3};
        changeInt(num);                 // num 仍然是 1
        changeArray(nums);              // nums[0] 变成 100
        reassignArray(nums);            // nums 仍然指向原来的 {100, 2, 3}

## package和import

    package用于指明该文件中定义的类，接口等结构所在的包
        一个文件只能有一个package声明文件，并且放在文件开头；命名全部小写；

    import是显式引入某个包下的类或者其他类型数据；
     

## 封装性

    对象的组织形式就感觉是与基于过程的另一种组织代码方式；
    本质还是高内聚，低耦合；更加方便理解；
    类似于前端的组件化，也是高内聚，低耦合；
    在java中class是一等公民，而函数是class的方法；

    怎么体现封装性呢？
    1、Java修饰符：private 缺省的 protected public

| 修饰符 | 本类内部 | 本包内 | 其他包的子类 | 其他包非子类 | 频率
| :--- | :---: | :---: | :---: | :---: |:---: |
| private | √ | × | × | × | 高 |
| 缺省 | √ | √ | × | × | 低 |
| protected | √ | √ | √ | × | 低 |
| public | √ | √ | √ | √ | 高 |

### 构造器

    类的成员：成员，方法，构造器
    构造器的作用：
        1.初始化对象
    如果没有写构造器，会有个默认的构造器，且构造器的权限与类声明的权限相同；
    构造器也有访问限制，类似变量的可访问性；
