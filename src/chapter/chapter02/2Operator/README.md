# 运算符

## 算术运算符

`+` `-` `*` `/` `%`

整型相除会截断小数部分；浮点相除保留小数。

## 赋值运算符

`=` `+=` `-=` `*=` `/=` `%=` 以及位运算对应的 `&=` `|=` 等。

## 自增自减

`++` `--` 前缀先改值再参与表达式，后缀先参与表达式再改值。

## 关系运算符

`==` `!=` `<` `>` `<=` `>=`，结果为 `boolean`。

## 逻辑运算符

`&&` `||` `!`，具有短路特性：`&&` 左侧为 false 时不计算右侧；`||` 左侧为 true 时不计算右侧。

## 位运算符

`&` `|` `^` `~` `<<` `>>` `>>>`，作用于整型的二进制位。

## 三元运算符

`条件 ? 表达式1 : 表达式2`
